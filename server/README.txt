ASTRAL NEXUS RPG - LOCAL TEST SERVER

1. Extract this entire folder to a normal folder, for example Desktop\AstralNexusServer.
2. Double-click START.bat.
3. On first start, the launcher downloads a private Java 21 runtime (if Java 21+ is not already installed) and the Paper 1.21.4 server. Internet is required for this first start.
4. Read https://www.minecraft.net/eula. If you accept it, type exactly: I AGREE
5. Wait until the console says Done.
6. Start Minecraft Java Edition 1.21.4 and connect to the server address: localhost
7. Try the plugin commands in chat: /astral help, /astral start, /astral profile
8. To stop the server, type stop in the server console and press Enter.

The server is configured for local testing. It does not configure router port forwarding or expose the server to the Internet. Keep START.bat, start-server.ps1, plugins, and all server files together. World data is stored in this folder.

Requirements: 64-bit Windows, internet on first launch, and enough free disk space. Default memory limit: 2 GB. The plugin targets Paper / Minecraft 1.21.4.
